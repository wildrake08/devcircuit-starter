# New software system

This is a thin DevCircuit application starter. It does not contain the DevCircuit kernel.

Initialize the application in this repository:

```sh
uvx --from https://github.com/wildrake08/devcircuit/releases/download/v1.0.0/devcircuit-1.0.0-py3-none-any.whl devcircuit --root . create my-application
```

Then start the guided conversation:

```sh
uvx --from https://github.com/wildrake08/devcircuit/releases/download/v1.0.0/devcircuit-1.0.0-py3-none-any.whl devcircuit --root . chat
```
